# Migration Guide — Novix UI

## From 0.9.x → 1.0.0

No breaking changes. Update the dependency and continue:

```bash
npm install @novix-ui/react@^1
```

## From other libraries

Full guides live at `/docs/migration`:

- shadcn/ui
- Chakra UI
- Material UI
- Ant Design
- Tailwind UI
- Bootstrap

Each guide includes API mapping tables, token mapping, and copy-paste replacements.
