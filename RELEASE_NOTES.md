# Novix UI 1.0.0 — Release Notes

Novix UI is generally available.

## Highlights

- **60 components** covering layout, forms, overlay, navigation, data, feedback, and premium primitives (Marquee, Ticker, Comparison, Cursor, Announcement, Rating, Snippet, Status).
- **Signature design language.** Moon-Edge highlights, Halo Hover, Press Sink physics, Squircle radii, Aperture transitions.
- **Token-driven theming.** OKLCH palette, first-class dark mode, one CSS variable to rebrand.
- **Motion-safe.** Every animation respects `prefers-reduced-motion`.
- **Accessible by default.** WCAG AA, keyboard-first, focus-visible, screen-reader tested.
- **DX.** Full TypeScript, tree-shakeable ESM + CJS, `sideEffects: false`, CLI, Storybook, four example apps.

## Install

```bash
npm install @novix-ui/react
```

## Breaking changes

None from 0.9.x. Nova 1.0 is API-stable.
